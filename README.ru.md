# relbp810: драйвер Canon LBP-810 для 64-битной Windows

[English](README.md) | **Русский**

relbp810 — драйвер с открытым исходным кодом для лазерного принтера Canon LBP-810. Работает в Windows с 7 SP1 по 11, в 64- и 32-битных версиях.

Canon выпускала драйверы LBP-810 только для 32-битной Windows, поэтому на 64-битных системах драйвера для этого принтера нет. relbp810 — новый драйвер на основе Unidrv от Microsoft. Чтобы его написать, мы провели реверс-инжиниринг оригинального драйвера Canon и протокола принтера CAPT. Страницы настроек выглядят так же, как в драйвере Canon.

## Установка

Скачайте `LBP-810-driver-<версия>.msi` со страницы [Releases](../../releases/latest).

1. Подключите принтер по USB и включите его.
2. Запустите MSI. Нужны права администратора.
3. В «Устройствах и принтерах» появится принтер **Canon LBP-810**.

Чтобы удалить драйвер, удалите «Драйвер принтера Canon LBP-810» в разделе «Приложения» или «Программы и компоненты».

> Пакет драйвера подписан самоподписанным сертификатом проекта. Чтобы Windows приняла драйвер, установщик добавляет этот сертификат в хранилища компьютера «Доверенные корневые центры сертификации» и «Доверенные издатели». При удалении драйвера сертификат удаляется. Если не хотите доверять нашему сертификату, соберите MSI сами. Тогда он будет подписан сертификатом, созданным на вашем компьютере.

## Состояние

- **Работает:** печать по USB (A4, Letter, Legal, B5, конверты и произвольный размер, 600 или 300 dpi), плотность тонера, экономия тонера, «нет бумаги» и другие ошибки принтера в очереди печати, повторная отправка страниц после ошибки, страницы настроек как у Canon.
- **Проверено:** Windows 10 x64 с настоящим LBP-810.
- **Пока не проверено:** Windows 7, 8.1 и 11, 32-битная Windows.
- **Пока не сделано:** окно состояния принтера Canon, наложение (overlay), масштабирование и несколько страниц на листе.
- **Язык интерфейса:** только русский. Интерфейс повторяет русскую версию драйвера Canon.

Нашли ошибку? Создайте issue: укажите версию Windows и опишите, что произошло.

## Как это устроено

| Файл | Назначение |
|---|---|
| `CNLB810.GPD`, `CNLB810.INI` | Мини-драйвер Unidrv: размеры бумаги, разрешения и параметры принтера |
| `CNLB810R.DLL` | Модуль отрисовки: сжимает каждую страницу в SCoA и формирует задание CAPT |
| `CNLB810L.DLL` | Языковой монитор: общается с принтером по CAPT через USB, сообщает его состояние и повторно отправляет страницы после ошибок |
| `CNLB810U.DLL` | Модуль интерфейса: три страницы настроек Canon и их диалоги |
| `LBP810CA.DLL` | Действия установщика MSI: устанавливает и удаляет драйвер, очередь печати и сертификат |

Мы изучили 32-битный драйвер Canon (`CAP1K.DLL`, `CAP1EMN.DLL`, `CAPMONK.DLL`, `CAP1UIK.DLL`) в дизассемблере и проверили то, что узнали о протоколе CAPT, на настоящем принтере. Код в репозитории — новая реализация для Unidrv. В двух местах результат должен точно совпадать с Canon: при сжатии SCoA и в образце на странице «Качество». Там наш код повторяет алгоритм Canon и сверен с оригинальными DLL бит в бит.

## Сборка

Понадобятся:

- Windows 10 или 11
- Visual Studio 2022 или новее либо Build Tools for Visual Studio с рабочей нагрузкой «Разработка классических приложений на C++» (MSVC для x64 и x86 и Windows 10/11 SDK). Проект проверен на Visual Studio 2026.
- Python 3.8 или новее в `PATH` (скрипты используют только стандартную библиотеку)
- Windows PowerShell 5.1, он входит в Windows

Чтобы собрать MSI, выполните в корне репозитория:

```bat
.\release.cmd
```

Результат — `out\LBP-810-driver-<версия>.msi`. `release.cmd` выполняет три шага, каждый можно запустить и отдельно:

1. `build.cmd` компилирует все DLL для x64 и x86. Драйвер попадает в `out\package`, действия установщика — в `out\setup`, диагностическая утилита `captcli.exe` — в `out\tools`.
2. `scripts\make-package.ps1` создаёт каталог безопасности и подписывает пакет. При первом запуске он создаёт в вашем личном хранилище самоподписанный сертификат подписи кода `CN=relbp810 LBP-810 driver (self-signed)`. Следующие запуски используют его же.
3. `scripts\make-msi.py` упаковывает `out\package` в MSI.

**Иконки Canon.** Иконки и картинки на страницах настроек принадлежат Canon, поэтому их нет в репозитории. `build.cmd` берёт их из `CAP1UIK.DLL` оригинального драйвера Canon. Положите папку оригинального драйвера `LBP-810_R110_V110_Win_x32_RU_7` в корень репозитория или укажите в переменной окружения `CANON_DRIVER` папку, где лежит `CAP1UIK.DLL`. Без этих файлов сборка подставит пустые заглушки. Драйвер работает, но на страницах настроек не будет иконок.

**Версии.** Windows не заменяет файлы драйвера, если такая версия уже установлена. Прежде чем раздавать новую сборку, увеличьте `VER_REV` в `src\driver\version.rc.h` и `DriverVer` в `src\driver\inf\CNLB810.INF`. `make-msi.py` проверяет, что они совпадают.

## Разработка

- Чтобы установить, обновить или удалить драйвер из `out\package` без MSI, запустите от администратора `scripts\install.ps1`, `scripts\update.ps1` или `scripts\uninstall.ps1`.
- `scripts\testprint.ps1` печатает тестовую страницу, а `scripts\diag-install.ps1` собирает диагностику установки.
- `out\tools\<arch>\captcli.exe` общается с принтером напрямую. Например, `captcli status` показывает состояние принтера, а `captcli testpage` печатает тестовую страницу.
- В `src\tools\dev` лежат тестовые утилиты, которые собираются вручную. Они снимают скриншоты интерфейса, запускают языковой монитор вне спулера и сверяют наш код с DLL Canon бит в бит.

```
src/common    протокол CAPT, сжатие SCoA, формат задания печати
src/driver    GPD, INF и DLL драйвера (render, langmon, ui, res)
src/setup     действия установщика MSI
src/tools     captcli и утилиты для разработки
scripts       скрипты упаковки и разработки
```

## Правовая информация

relbp810 — неофициальный проект. Он не связан с Canon Inc., не одобрен и не поддерживается ею. Canon и LBP — товарные знаки Canon Inc. Проект упоминает их только для того, чтобы назвать принтер, с которым работает драйвер.

Мы провели реверс-инжиниринг оригинального драйвера только для того, чтобы принтер работал в современных версиях Windows. В репозитории нет бинарных файлов и графики Canon. Чтобы интерфейс был привычным, диалоги настроек повторяют расположение элементов и русские тексты драйвера Canon. MSI-файлы на странице Releases собраны с оригинальными иконками.
